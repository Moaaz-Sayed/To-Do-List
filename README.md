# 📝 To-Do List Web App

A simple and clean to-do list application to help you manage your daily tasks efficiently. You can add, edit, delete, and mark tasks as completed. Your tasks are saved automatically in your browser using Local Storage.

## ⚙️ Features
- Add new tasks with auto-generated date and time
- Edit existing tasks
- Delete tasks
- Mark tasks as done or undone
- Tasks are saved in Local Storage (no backend required)
- Fully responsive design for mobile and desktop
- RTL support and Arabic interface

## 🧪 Built With
- HTML
- CSS
- JavaScript (Vanilla)
- LocalStorage API

## 🚀 How to Use
1. Click the ➕ button to add a new task.
2. Use the ✏️ button to edit, the 🗑️ button to delete, or the ✅/❌ button to toggle task completion.
3. Your tasks are saved automatically and persist after reloading the page.
